# OwnVoice 0.2 验收报告

2026-10-23。四技能套件已通过预设的本轮模型与 Codex CLI 宿主门槛。模型和宿主测试候选为 **0.2.0rc1**；已保留该快照，并仅晋级版本元数据为 **0.2.0**，行为与技能指令不变。未公开上传 GitHub，也没有运行远程 GitHub Actions。

## 实际交付能力

- 无档案直接处理代码、科研和邮件；明确要求时才进入可选档案流程，兼容现有 v1。
- 参考样例归纳表达习惯，保留领域/语言隔离、未知项和任务约束。三个成品技能不再加载建档说明。
- Python 辅助工具验证 JSON/Schema、明确数值与单位、日期格式、来源 ID 和角色绑定；原稿不自动修改。检查状态区分 passed、failed、not_run，失败允许一次反馈修订。
- 明确区分语法、接口、有限行为及正文复核。结构化账本正确不代表正文必然正确；模型复核不是机械证明或人类评审。
- Codex 安装到当前官方用户级目录，配套隔离运行环境、显式升级、统一版本切换、回滚及仅移除自有链接的卸载。

## 模型实验

原候选验收使用 **110/120 个新增 CLI 任务**：2 次预检、18 次开发生成/修订、72 次留出生成/修订、9 次常规盲评、8 次真实宿主任务、1 次错误标记有效性审计。随后实际用户目录验收增加 6 次集成调用及 1 次邮件反馈修订，当前合计 **117/120**、累计 **356/359**。原有 239 条记录、原候选摘要和全部留出答案保留，没有重生成留出答案。后续发现的邮件期限歧义、修订和实际发现证据见[用户级安装验收](user-install-v02.md)。

所有新任务均显式请求 `gpt-6-luna / medium`，无型号回退。返回事件未提供型号标识时按“请求路由已固定、返回型号未报告”记录。计数单位是 CLI 任务，宿主工具循环中的底层请求不被冒充为精确 API 次数。

三组使用相同的任务事实、嵌套 Schema、样例和检查反馈，均有初稿及一次修订机会。开发为 3 个任务；留出为 6 个新任务、每个两套风格，共 12 个成品/组。模型比较使用文本生成与外部确定性反馈；宿主发现/脚本执行另做真实验收。

正文复核的日历邮件中，首轮标记把“未在正文重复未知付款日期”和“未重复写出发件人 Taylor 为模板接收者”算为实质错误。一轮新匿名标签的 Luna 审计依据原始题面判定 OwnVoice 四个标记及清单一个标记不成立；普通提示缺少未批准状态被认可，正文缺少会议时段被判无法确定，继续保留未解决。原始输出、标记、评分和审计均保存，没有改答案、改门槛或反复求通过。**这是一轮事后评分审计，不是新增的独立留出质量证据。** 细节见[测量审计](release-v02-measurement-audit.md)。

## 宿主与软件验证

八项真实 Codex CLI 验收全部通过：代码、科研、邮件、档案四个显式入口；代码、科研、邮件三个隐式入口；一个不应调用技能的无关请求。适用案例要求有完整技能读取、成功检查命令以及与成品哈希对应的实际报告。无档案案例未调用建档技能。源任务/Schema/约束的不可修改要求另行核对。

隐式科研最初被证据解析器误判：完整技能已读出，但串联命令末尾的目录搜索失败。现以实际完整内容确认读取，保留原判定并补正反例；没有重跑模型。该修正与正式留出输入无关。

候选压缩包已在独立临时目录解压，54 项软件测试、四技能静态校验、实际隔离安装、安装后辅助工具正反例及卸载均通过；125 个包内文件的清单哈希一致。0.2.0 最终包也已通过同样的解压、54 项测试、安装、检查器正反例和卸载验收；另已实际完成带隔离运行环境的 rc1→0.2.0 升级及回滚，两个版本的检查器均正常工作，未新增模型调用；报告补记完成事实后重新打包，并核对执行文件与已测包完全一致。CI 已配置 Linux/macOS、Python 3.9/3.12，无付费模型调用。当前实际宿主证据来自本机 macOS；远程 CI 未运行，Claude 未做实机验证。

## 发布与适用边界

本轮门槛是：12 份 OwnVoice 留出成品通过明确契约、没有未解决实质来源错误、至少 5/6 风格配对并覆盖三领域、8/8 原生宿主验收，且产品与冻结候选匹配。结果可由 `scripts/report_release.py` 从本地保留的记录重建，公开汇总见[JSON](release-v02.json)。

0.2.0 晋级仅修改版本元数据，保留 rc1 快照及原模型输入；任何新增行为或指令修改都会使冻结匹配门槛失败。晋级后的压缩包已重新通过解压安装和辅助工具正反例。

提示字符合计（留出初稿及修订）：普通提示 135,644、完整清单 144,578、OwnVoice 234,539。缓存/固定 CLI 开销使它们不能直接换算价格。风格匹配的点估计不支持统计优势、真实用户偏好或广泛个人风格结论；后续应减少无效指令并验证真实修改成本。
